# Run and deploy CodeStalker: your new friend in CP
An immersive problem recommendation engine and practice tracker for Competitive Programming in Codeforces. 
Get recommended problems as per your level, find problems with similar tags and save your progress as you go.

Link: https://code-stalker-zeta.vercel.app/

## NOTE:
1. The website uses your browser's localStorage to save progress. If you ever change your browser or device, that progress is lost.
2. To reliably keep your progress safe, regularly export your progress by clicking "Export Backup". Then on a fresh browser, you can import the file to update your progress.
